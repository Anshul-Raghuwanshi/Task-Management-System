## Task Management System (MERN Stack Project)
## Overview
This is a full-stack MERN (MongoDB, Express, React, Node.js) project for a task management system. The backend handles API requests and database interactions, while the frontend provides a user-friendly interface.

## Features
Backend: Built with Express.js and MongoDB as the database.

Frontend: Developed with VITE + React.js for a dynamic and responsive UI.

RESTful APIs for seamless communication between frontend and backend.

## Prerequisites
Node.js (version 14+)
npm or yarn
MongoDB instance (local or cloud)

## Install Dependencies:
## Backend
cd backend

npm install

npm run dev

## Frontend
cd frontend

npm install

npm run dev
